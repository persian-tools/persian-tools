Persian Tools provides two BIN-based lookups for Iranian cards:

- `getBankNameFromCardNumber` returns only the issuing bank's Persian name.
- `getBankLogoWithCardNumber` returns the name and URL of its packaged SVG logo.

## Function

```ts
getBankNameFromCardNumber(digits?: number | string): string | null | undefined
getBankLogoWithCardNumber(cardNumber: string): CardBankInfo | null
```

```ts
import { getBankNameFromCardNumber } from "@persian-tools/persian-tools";

getBankNameFromCardNumber("6219861034529007"); // "بانک سامان"
getBankNameFromCardNumber("603799"); // "بانک ملی ایران" — BIN-only works
getBankNameFromCardNumber("9999999999999999"); // null — BIN not in the table
getBankNameFromCardNumber("123"); // null — too short
getBankNameFromCardNumber(undefined); // undefined
```

### Bank name and logo

```ts
import { getBankLogoWithCardNumber } from "@persian-tools/persian-tools";

getBankLogoWithCardNumber("6219861034529007");
// {
//   name: "بانک سامان",
//   logo: "data:image/svg+xml,..."
// }

getBankLogoWithCardNumber("603769"); // BIN-only works
getBankLogoWithCardNumber("9999999999999999"); // null
```

```ts
interface CardBankInfo {
	name: string;
	logo: string;
}
```

The logo is shipped with the package as an SVG asset. Depending on the consuming bundler it may be represented as an emitted asset URL or an SVG data URI. Both forms can be used directly as an image source:

```tsx
const bank = getBankLogoWithCardNumber(cardNumber);

return bank ? <img src={bank.logo} alt={bank.name} /> : null;
```

## Return type — three states

| Return      | Meaning                                               |
| ----------- | ----------------------------------------------------- |
| `string`    | Issuing bank's Persian name                           |
| `null`      | Length out of `[6, 16]`, or BIN not in the data table |
| `undefined` | Falsy input — function did not attempt the lookup     |

Use `=== "string"` rather than a truthy check.

## Behaviour

1. Falsy input → `undefined`.
2. Stringified length must be in `[6, 16]`. Otherwise → `null`.
3. Take the leading 6 characters as the BIN.
4. Look up in the `cardBank` data table (`src/modules/getBankNameFromCardNumber/banksCode.skip.ts`).
5. Return the Persian bank name or `null`.

## Pitfalls

- This is a **lookup, not a validator**. A nonsense tail (e.g. `"603799 garbage"`) doesn't matter as long as the BIN matches AND total length is in range. For checksum validation, use `verifyCardNumber`.
- `getBankLogoWithCardNumber` inspects only the first 6 characters and returns `null` for an unknown or incomplete BIN.
- **Persian/Arabic digit input is not normalized.** Pre-convert with `digitsFaToEn` / `autoConvertDigitsToEN` if input may contain them.
- The data table is curated; new banks may not appear until added.

## Composition with `verifyCardNumber`

```ts
import { autoConvertDigitsToEN, verifyCardNumber, getBankNameFromCardNumber } from "@persian-tools/persian-tools";

function inspect(raw: string) {
	const norm = autoConvertDigitsToEN(raw.trim());
	const valid = verifyCardNumber(norm) === true;
	return {
		valid,
		bank: valid ? getBankNameFromCardNumber(norm) : null,
	};
}
```
